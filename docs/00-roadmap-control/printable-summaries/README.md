# Printable Roadmap Summaries

These documents are short management snapshots designed to print on one page each.

They are deliberately non-authoritative. If a summary differs from its linked child
roadmap or the root portfolio control, the authoritative roadmap wins.

Refresh the affected summary whenever a portfolio reconciliation materially changes its
source roadmap, especially its open CRs, `Now`, `Next`, evidence gates or immediate
decision.
