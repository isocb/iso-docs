# FUND Implementation Confirmations

This folder is for new implementation confirmation documents.

Confirmation documents record what was actually changed:

- slice name and date;
- files changed;
- schema/migration changes, if any;
- checks run;
- what was deliberately not implemented;
- risks and follow-ups.

Historical confirmations may remain in `implementation/` until they are next touched. New confirmations should go here.
